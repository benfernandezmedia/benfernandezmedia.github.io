During the weekend, I have been considering adding more features to the website, bypass limitations that the Hextra theme has provided by adding some shortcodes, pages, and some overrides (if the theme allows it).

<!--more-->

As I do all of the experimental stuff on the private developer build of the website on my computer, I expect to ensure all of the functions works, no matter how programming the page layout is at this point.

Here are changes you will expect on this new build:

## Improved publishDate on blog posts

As I did some exploration, I've noticed that the date and time on the posts I've done is usually set to "Yesterday at 8:00PM" when the `date` frontmatter is configured on the draft of the post.

To fix this, as you are reading this post, this was written in {{< icon "obsidian" >}} **Obsidian** so I can properly add the current date and time with the `publishDate` frontmatter.

This also renders properly in your RSS Feeder too, which is a good thing for me!

During this time, all blog posts will be rewritten, including posts related to MediaPlay, as there may be some grammar errors or proofreading that needs to be fixed.

## RSS Feed Icon on Navigation Menu

Instead of navigating your way to the {{< icon "question-mark-circle" >}} **Help and Information** page to subscribe to the main site feed, an RSS icon will be implemented on the navigation menu bar so you can subscribe to the main website feed instantly.

## Visual Upgrades

There's nothing major for the visuals but a small minor change to the look and feel of the global theme if applied correctly.

Some work will be done in hopes to achieve a major visual update to the site.

I won't disclose everything here for this section but there may be some new pages coming to the website but it will be a secret for now.
